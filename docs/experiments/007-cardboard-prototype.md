# 实验 007：纸板机械原型与整机联动验收

- 状态：**已验收**（依据用户实物观察，2026-11-08 报告）
- 日期：2026-11-08（用户报告验收结论的日期；实际搭建时间未单独记录）
- 前置实验：[006 双舵机与动作/情绪联动](006-dual-servo.md)（2026-11-07 已验收）

## 1. 目标

把已分别验收的 SH1106 OLED 表情、两只 SG90 舵机、动作序列与情绪联动装进一个纸板机械结构，确认安装后的整机仍能正常运行。本实验只验证机械安装与已有固件的联动，不引入新的电子模块、引脚或固件功能。

## 2. 硬件与接线

沿用实验 004–006 已确认的连接，没有在本实验中改动：

| 部件 | 连接 |
| --- | --- |
| OLED（SH1106 路径） | VCC → 3V3、GND → GND、SDA → GPIO8、SCL → GPIO9，I²C 100kHz，地址 0x3C |
| 舵机 1 | 信号 → GPIO4（LEDC 通道 0），红线 → 外部 5V 正极，棕线 → 外部电源负极 |
| 舵机 2 | 信号 → GPIO5（LEDC 通道 1），与舵机 1 共用外部 5V |
| 共地 | ESP32 GND 与外部 5V 电源负极相连 |
| 开发板供电 | 实验期间仍由 USB 供电；外部 5V 只供舵机 |

纸板结构的材料、尺寸、固定方式、摇臂长度和装配细节**没有测量或记录**，本文不给出数值。

## 3. 验收标准

1. 两只舵机安装在纸板结构上后仍能由固件驱动，行程不被结构卡死。
2. OLED 表情画面在安装位置可见，表情切换不受机械结构影响。
3. 情绪命令（`mood ...`）能同时带动表情与两只舵机的动作，联动关系与实验 006 一致。
4. 上电后不自动运动，停止命令仍能关闭两路 PWM。

## 4. 执行过程

用户搭建纸板机械原型，装入 OLED 与两只舵机，烧录实验 006 第二阶段固件后通电运行，并观察表情与动作联动。2026-11-08 用户向本项目报告：纸板机械原型已经完成，安装后的两只舵机和 OLED 情绪联动运行正常。

## 5. 结果

- 纸板机械原型完成，安装后的两只舵机与 OLED 情绪联动获用户确认正常，实验 007 记为**已验收**。
- 证据类型：用户实物观察。没有保存照片、视频、串口日志或测量数据；这些材料未进入仓库。
- 用户没有报告卡顿、异响、结构干涉、复位或供电异常。

## 6. 未测量与未验证的内容

以下项目没有数据，不能由本次验收推断：

- 纸板结构尺寸、重量、摇臂长度与关节间隙。
- 舵机电流、电源电压跌落、发热与长时间运行稳定性。
- 实际角度、动作幅度、方向标定、负载转矩、回差与噪声。
- 结构在堵转、连续快速换向或外部碰撞下的表现。
- 摄像头、麦克风、扬声器等其他模块的安装与供电。

若后续调整结构或增加负载，应重新做一次实物观察，不能沿用本次结论。

## 7. 故障处理

本实验没有报告故障，未执行故障排查。若安装后出现动作受限，先断开外部 5V，检查摇臂与纸板是否干涉，再按实验 006 的限位与供电检查步骤处理。

## 8. 学习要点

- 软件验收（串口检查、PWM 输出）和机械安装验收是两件事；装进结构后需要重新观察，不能只凭日志判断。
- 表情与动作共用同一套控制器，机械安装不应改变固件行为；本次没有为此修改代码。
- 没有测量的机械与电气参数应明确留空，不能用“运行正常”代替定量结论。
